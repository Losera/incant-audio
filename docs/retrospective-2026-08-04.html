05Decisions and open questions

ADR-021 — PluginSpec is not built

2026-08-04 · Accepted · uncommitted
Decision — Do not build PluginSpec. Parameter structure stays discovered at compile time via MapUI/ParamCapture into ParamInfo. I/O topology is read live from the compiled dsp instance and never declared.
Revisit if — Generated plugins begin exhibiting layout intent (grouping, ordering, control-type preference) in a meaningful fraction of a larger corpus. The 0/19 result is what kills this; a non-zero result reopens it.
Addendum, 2026-08-04, Brief F: validatePatch()'s input-channels check fires on entries 10 and 18 and no other entry; entry 1's mono/stereo reversal remains uncaught — "a different mechanism, still not built." docs/decisions.md:529–579
